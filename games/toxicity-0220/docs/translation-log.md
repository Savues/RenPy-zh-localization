# 翻译档案 — TOXICity 0.22.0

译文全部人工逐条撰写，**没有使用任何机器翻译或在线翻译 API**。

---

## 工作流程

本作的翻译不是一遍过的，分四个阶段：

### 阶段一 · 主线（`script*.rpy` / `scenes_*.rpy`）

按章节推进，术语在开工前就钉死（见 `glossary.json`）。
正文语言刻意保持**粗俗、口语、带脏话** —— 原作是一部成人向视觉小说，
把台词翻得太干净会让人出戏。原文中相当一部分粗口直接保留了英文
（例如 `What the fuck!? Marley?`），这是风格选择，不是漏翻。

拟声词（`Hnnnn~~~`、`Slpppp~~~` 一类）**逐处单独处理**，不套统一模板：
同一个 `Ohhhhh~~~ hooooo~~~` 在不同场景里译成过 `哦哦哦~~~ 哦呜呜呜~~~`、
`哦哦哦~~~ 哦呜呜~`、`噢噢~~~ 呼喔~~~` 等好几种。耳朵和呼吸的节奏本来就在变，
统一成一个词反而假。

统计变化也是照着耳朵走的，所以 `data/tl_trans.json` 里同一个英文 key
对应多个中文值的情况有 868 组 —— 数据库保留首次出现的那个，
**脚本里各处用的仍是各自不同的译法**，没有被合并。

### 阶段二 · 界面与图鉴（`screens.rpy` / `specialscreens.rpy` / `options.rpy`）

菜单、存档、图鉴、成就、章节标题卡。
`specialscreens.rpy` 里有大量日期卡（`6月10日 上午10:15` 之类），
统一成「月日 星期 + 上午/下午 + 时:分」，和游戏里 `june_10_1015` 这类标签一一对应。

图鉴里的 431 个 ASCII 字面量绝大多数是资源路径和内部标识符
（`/gui/gallery/ach_chapter1_hover.webp`、`shelley_ch8_sex2`），
不翻译。另有三个刻意保留的 leetspeak 字符串
（`3r4mThgIn`、`3clff0 34+`、`4om3 ag@ln`）—— 那是游戏里的故障风标题卡，
原文就是故意看不清的。

### 阶段三 · Mod（`mod/` 三个脚本 + 增量剧情）

Gugatron Mod 的界面、作弊菜单、解锁列表、颜色宏说明全部汉化。
Mod 往 `script*.rpy` 里插入了新剧情，增量部分按
[approach.md](approach.md) 描述的方式移植：主体保持既有译文，
只新译 Mod 插入的 134 行。

### 阶段四 · 校对与返修

定稿前做内容层校验，揪出并修复了四类问题，
逐条记录在 [approach.md](approach.md#校验时发现的四个真实缺陷)。

## 术语表

钉死在 [`glossary.json`](glossary.json)，这里只列要点。

**角色**（这些名字**原版 `define_default.rpy` 里就已经是中文**，
不是翻译选出来的 —— 收录它们是为了防止以后漂移）：

| 英文 | 中文 | 备注 |
|---|---|---|
| Kallie | 卡莉 | ⚠️ 原脚本里另有 `Kalliie` / `Kaliie` 两种拼写，已统一 |
| Laura | 劳拉 | ⚠️ `Raul` 是另一个人，译作**劳尔**，两者极易混 |
| Shelley | 雪莉 | |
| Eve | 伊芙 | ⚠️ 不能译成「艾芙」 |
| Nancy | 南希 | 返修时统一了 24 处 `南茜` |
| Keith | 基思 | 返修时统一了 1 处 `基斯` |
| Andrew | 安德鲁 | |
| Otis | 奥蒂斯 | |

**关系数值**：`Trust` 信任 / `Desire` 欲望 / `Love` 爱意 / `Friend` 好感 / `Anxiety` 焦虑。

这里有个坑值得记下来：Mod 另有一套自己的计数，叫**情欲点**
（`define pkl = "{color=#AA00FF}(情欲点)"`），和 `Desire` 不是一个东西。
两者名字相近，`glossary.json` 里因此没有把「情欲」列为 `Desire` 的禁用译法 ——
`情欲` 在正文里也正常出现（54 处 `不安`、94 处 `压力` 同理，
都是普通中文词，不是数值标签，**不能**列进 `banned`）。
`check.py` 的禁用检查是纯子串匹配，一刀切会误伤。

**场所**：`Ladies' Room` 洗手间 / `Student Center` 学生中心 / `New York` 纽约。

英文里其实有两个说法，刻意做了区分：
**proper noun 的 "Ladies' Room"**（角色会专门提到名字的那个房间）
译 `洗手间`；**普通的 "ladies' bathroom"** 一律译 `女洗手间`。
glossary 只钉死前者。

## 标点与排印

中文用**全角标点**：`，。？！：；「」（）`。
原作的破折号 `——` 和省略号 `……` 都按中文习惯成对使用。

语气词（`…~~~` 这类拖长音）保留原作的 `~~~` 数量，不做归一化 ——
它们承载的是节奏。

原文里 `[rd]`、`[rrd]` 这类 Mod 标记，以及紧跟其后的圆括号块，
在译文里**结构原样保留**，只翻圆括号内部的内容：

| | 原文 | 译文 |
|---|---|---|
| 标记 | `[rd]` | `[rd]` |
| 角色与数值 | `Kallie\Laura Anxiety +1` | `卡莉\劳拉 焦虑 +1` |
| 角色与数值 | `Kallie\Laura Trust -1` | `卡莉\劳拉 信任 -1` |

整句对照（同一条台词的英文与中文）：

> `Don't.` + `Later` → `不要。` + `稍后`

## 字体

译文里用到 2,956 个非 ASCII 字符，MiSans 命中 2,955 个，
唯一未覆盖的是 U+FEFF（零宽字符 / BOM），渲染为空白属正常。
已逐字渲染比对 `.notdef`，没有出现「cmap 有字但画出豆腐块」的情况。

**硬约束：译文里不用 emoji。** MiSans 不含 emoji 字形，
符号区基本是空的（U+2764 ❤、U+2665 ♥ 这些都没有），
能用的只有 `● ■ ★ ☆ ▲` 这类几何图形。
