Taken unmodified from one upstream archive
  https://hyperos.mi.com/font-download/MiSans_Global_ALL.zip
and shipped unmodified, under three filenames:

  MiSans-Regular.ttf   the face that actually renders this patch. The game asks
                       for "fonts/msyh.ttc" in 291 places (every gui.*_font
                       slot plus inline {font=...} tags); the patch's shim
                       rewrites that request to this file at startup rather than
                       overwriting msyh.ttc on disk.
  MiSans-Medium.ttf     the weight actually used for emphasis. The same map
                       sends every bold request here, so it covers both the
                       ~93 {b} tags in the scripts and style.say_dialogue,
                       which the patch sets bold for dialogue legibility.
                       MiSans ships 400 / 500 / 700; measured ink coverage of
                       a sample CJK line at 48px is 1.00x / 1.11x / 1.64x,
                       so 700 reads too heavy for body text and 500 is the
                       middle. Flip one line in patch/zzz_font_misans.rpy to
                       change the choice.
  MiSans-Bold.ttf      the 700 face. Kept so that choice can be flipped
                       without a new download; nothing references it while
                       _MS_STRONG points at Medium.

PROVENANCE OF THE THREE FILES
-----------------------------
MiSans-Regular.ttf here is byte-identical to the copies in this repository at
games/cosycafe-0142/assets/fonts/, games/sinfulsummer-chapter36/assets/fonts/
and games/scionsofthedivine-01/assets/fonts/ -- same 8,073,152 bytes, same
SHA-256 -- so those packages ship the same MiSans build. MiSans-Bold.ttf is
byte-identical to the copies in games/cosycafe-0142/assets/fonts/ and
games/scionsofthedivine-01/assets/fonts/ (7,959,920 bytes).
MiSans-Medium.ttf exists only in this package.

An earlier version of this file claimed MiSans-Regular.ttf was "byte-identical
to the copies bundled in games/cosycafe-0142/assets/fonts/ and
games/eden-chapter5/assets/fonts/, so every game in this repository ships the
same MiSans build". The Eden half of that was wrong, and has been corrected:

  The file at games/eden-chapter5/assets/fonts/MiSans-Regular.ttf is a
  different build -- 7,924,400 bytes, SHA-256 7172aa1b... -- not the
  8,073,152-byte build shipped by the four packages above. Eden's own licence
  records where it came from: a direct download of the single-file
  MiSans-Regular.ttf (version 2.000) from Xiaomi's CDN, not the
  MiSans_Global_ALL.zip archive recorded at the top of this file.

The mistake is written down because the generalisation is easy to repeat. A
hash match against another game's asset proves two files are the same bytes; it
says nothing about the assets of a game that was never compared. Four matching
packages and one different one is the actual shape of this repository.

WHY A REPLACEMENT MAP INSTEAD OF OVERWRITING THE FONT FILE
---------------------------------------------------------
TOXICity already ships fonts/msyh.ttc (Microsoft YaHei), which has full CJK
coverage -- Chinese renders fine before this patch. MiSans is a typographic
upgrade, not a tofu fix. That is why nothing is overwritten: uninstalling
restores the exact original game and the player is left with the game's own
font, not a patched one.

NOTE ON REDISTRIBUTION
----------------------
Xiaomi markets MiSans as free for commercial use, but the font file carries no
licence text: its name table has no licence description (nameID 13) and no
licence URL, and the copyright line ends in "All Rights Reserved". Unlike SIL
OFL, which grants redistribution explicitly, this file grants no written
redistribution right. Shipping it inside a public repository is a judgement
call made by whoever publishes this package. Drop these three files and the patch
still renders -- the shim detects the missing font and leaves the game on
fonts/msyh.ttc (see docs/approach.md).
