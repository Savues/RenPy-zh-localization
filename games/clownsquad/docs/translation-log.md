翻译 API。**

## 润色轮次

### 第一轮：标点与格式

| 项目 | 处数 | 说明 |
|---|---|---|
| 直引号 → 中文引号 | 78 | `"…"` → `“…”`，与游戏 `scenechoice.rpy` 原有风格统一 |
| 漏译补回 | 1 | 一句英文两行，原译文只剩前半句 |
| 舞台提示多余空格 | 4 | `（比划着） （…）` → `（比划着）（…）`，与全文 260+ 处写法统一 |
| 术语不一致 | 1 | `是本尊？！` → `是野兽本人？！`，与「野兽」口径统一 |
| 标注统一 | 22 | `（低语）` → `（低声）`，whisper 系标注原本两种混用 |

润色后自检（全 0 才算合格）：半角标点紧邻中文 0、译文里残留英文直引号 0、半角破折号或
半角括号包中文 0、连续空格 0、标点前空格 0、中文之间全角空格 0、英文残留单词 0
（保留的拉丁字符全是 Reddit / Discord / Astreon / 论坛 ID 这类专有名词）、
疑似漏译的极端长度比 0。

### 第二轮：建译文库时暴露出来的错译

拼 `data/tl_trans.json` 时，同一句英文被翻成两种中文的地方会报出来。逐条看上下文，
有三处是真错：

| 原文 | 原译 | 改为 | 为什么 |
|---|---|---|---|
| `Yep.` ×2 | `稳定。` | `对。` | 上一句是 `Stable?`，把问句的词当答案抄回去了 |
| `Yes.` | `够了。` | `是的。` | `够了。` 是聪明的一次性处理，不能当成普通的是/否复用 |
| `YES!` | `明白了！` / `太好了！` | `太好了！` | `明白了！` 译的是 "Understood!" |

## 一句英文只能有一个译法（34 组）

译文库以英文原文为 key，所以同一句英文在游戏里出现几次就只能有一个中文。Clown Squad 里
有 34 组短叹词原本是分场景译的，**逐条看过上下文后统一了**。取舍本身写在
[`approach.md`](approach.md#4-译文库以英文原文为-key所以一句英文只能有一个译法)。

| 英文 | 统一为 | 理由 |
|---|---|---|
| `Why?` | 为什么？ | 8 处里只有 1 处是莉娜在逗亚当（「过来。」「干嘛？」），其余 7 处是真的在问原因 |
| `What?` | 什么？ | 中性的惊讶语气，8 处都立得住 |
| `Got it.` | 知道了。 | 5 处里 4 处是这个 |
| `Yeah.` | 嗯。 | 6 处全是附和，不是确认事实 |
| `I know.` | 我知道。 | 5 处里 4 处是平叙；`我就知道。` 只在一次「我就知道。」「变态。」的语境里才对 |
| `Yes.` | 是的。 | 见上 |
| `*Laughs*` | `*笑*` | 3 处里 2 处 |
| `Exactly.` | 正是。 | 3 处里 2 处 |
| `Excuse me?` | 你说什么？ | 3 处里 2 处 |
| `No.` | 不。 | 3 处里 2 处 |
| `What's that supposed to mean?` | 你这话什么意思？ | 3 处里 2 处 |
| `Who knows?` | 谁知道呢。 | 4 处，两句两；句号版适合当「谁知道啊」这种挡回去的语气 |
| `Y'know...` | 你知道不…… | 三处都是莉娜在铺垫下一句，`你知道不……` 最贴她的口吻 |
| `Yeah, yeah.` | 是是是。 | 3 处里 2 处 |
| `(And here I am.)` | （而我又在这儿。） | 2 处 |
| `(Right?)` | （对吧？） | 2 处 |
| `(That voice...)` | （那声音……） | 2 处 |
| `(Whispering) Love you.` | （低声）我爱你。 | 耳语表白要那个「我」，`爱你。` 把分量掉了 |
| `(Whispering) What the hell was that?` | （低声）你刚才说什么？ | 2 处 |
| `A couple of hours later.` | 几小时后。 | 2 处 |
| `But...` | 不过…… | 2 处；亚当说话偏「不过」 |
| `Eh?` | 嗯？ | 2 处 |
| `Exactly!` | 正是！ | 2 处 |
| `How?` | 怎么？ | **两个原句问的根本不是一回事**：一处问自行车钥匙怎么还的，一处问手指怎么补。两个具体译法都保不住，短形式至少忠实于原文那个光秃秃的 `How?` |
| `I see.` | 我明白了。 | 2 处 |
| `NO!` | 不！ | 2 处 |
| `No!` | 不！ | 2 处 |
| `Not quite.` | 还不算。 | 2 处 |
| `Right.` | 说得对。 | 另一处 `好吧。` 是碧翠丝在说服自己，不是附和 |
| `That's the one.` | 就是那个。 | 2 处 |
| `Then—` | 那么—— | 2 处 |
| `YES!` | 太好了！ | 见上 |
| `Yep.` | 对。 | 见上 |
| `You asked me to.` | 是你让我这么干的。 | 两句语境不同（一次是「叫你走」、一次是「叫你那样做」），这个通式两边都成立 |

## 界面残留覆盖（20 条）

`zz_zh_locale.rpy` 在 `init 999` 改写归档自带翻译表里的 20 条：

- **人名**：`Alicia` 的原译是「爱丽丝」，原文写的是 Alicia 不是 Alice → `艾丽西亚`
- **错译**：`Skips only the text that has been read.` 原译写成「选项后继续快进」→ `仅快进已读过的文本。`
- **制作人员里原封未译的 9 条**（`Translations`、`Special thanks to`、`Supporters` 等）
- **归档里完全缺失、游戏里仍显示英文的 6 条**（NSFW 提示、文字速度、A - D 切档位提示等）
- **顺带统一**：`Skip (A)` → `快进 (A)`

## 语气约定

| 角色 | 说话方式 |
|---|---|
| `mc`（亚当） | 毒舌、自嘲；括号内是内心独白，全角括号 |
| `r`（罗丝） | 街头俚语、粗粝，爱用 `ya` / `ain't` 那一类语气 |
| `ti`（蒂娅） | 苏格兰腔，粗犷不拘 |
| `li`（莉娅） | 冷峻精英、居高临下 |
| `an`（艾丽西亚） | 严重口吃，用中文叠字表现 |
| `L`（莉娜） | 活泼毒舌，和亚当互损 |

- `{b}...{/b}`、`[mc]`、`{w=0.8}` 等 Ren'Py 标签原样保留
- 成人场景按原作力度直译，不做机械统一，按上下文选词
- 角色名与专有名词见 [`glossary.json`](glossary.json)
