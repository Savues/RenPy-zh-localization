# 翻译日志 —— That New Teacher 0.9.0

## 译文来源

这一份汉化是**对发行方自带中文的修订**，不是从英文重译。

基线是下载包里 `game/tl/chinese/` 的那 19,402 个 translate 块。这份中文是机翻：
游戏自己的语言菜单给标了机器人图标，并在选择语言时写着
「标有机器人图标的语言为机器翻译。想帮忙改进译文吗？欢迎加入 Discord！」。

本补丁**不去掉那个标记**——标记的是基线译文，基线没有被重译，标记就还成立。
把标记抹掉等于宣称 43,108 行全部是人工重写，那是假的。

## 覆盖

| 口径 | 数量 |
|---|---|
| translate 块 | 19,402 |
| 玩家可见字符串（对白 + UI 串） | 19,112 |
| 已本地化 | **18,989（99.35%）** |
| ├─ 含汉字 | 18,881 |
| └─ 只改了标点 | 108 |
| 有意保留原文 | 123 |

「只改了标点」那 108 条是 `[player_name]...` → `[player_name]……`、
`[suz]!?` → `[suz]！？` 这类。它们不是漏译，只是中文里不出现汉字，
用「含汉字」去判定会全部误判成未译。判定规则是「值与英文原文不同即算已本地化」，
与 `tools/check.py` 判定 tl-blocks 条目「still in English」用的是同一条。

保留原文的 123 条逐条登记在 `docs/glossary.json` 的 `_kept_verbatim`，
`tools/verify_patch.cjs` 每次从补丁里重新数一遍并与该文件对照，对不上就失败。

## 最重要的修正：Sophia 与 Suzie 撞名

发行方把两位女主**都译成了「苏西」**。这是这一版最严重的问题——玩家在正文里
根本分不出说的是谁，而且这种错误不会以任何形式报错。

改法：Sophia → **索菲娅**（婚姓 Miller），Suzie 保留 **苏西**（娘家姓 Harris），
连带改掉 35 处硬编码「苏西」和 3 处「苏茜」。

改完之后 `苏西` 变成了苏西的**正确**写法，所以 `docs/glossary.json` 里
不能把它写成 Sophia 的禁用变体——那样会把 43 处正确的苏西全部报成错。
这个撞名因此不能靠 glossary 抓，单列成 `verify_patch.cjs` 里的一条守卫：
索菲娅与苏西各数一遍，任一个归零就失败。
`克拉丽莎`（Clarissa）与 `克莉丝`（Chrissy）当初也是同一类错，同样处理。

## 其余修正（按类别）

### 机翻把词看错了

| 原译 | 改 | 依据 |
|---|---|---|
| 安慰 | 控制台 | `Console` 是 Ren'Py 出错时的调试动作，不是「安慰」 |
| 酒吧 | 滑块 | 无障碍朗读串 `bar` 是 UI 滑块；游戏里另有一间真酒吧 |
| 过度 | 转场效果 | `Transitions` 是转场，不是「过度」 |
| 快进 | 自动前进 | `Auto-Forward`，与 `Auto`=自动 一致 |
| 留言 | 信息 | `Messages` 是短信，语音留言另作「语音留言」 |

### 同一设定两种译法

- 称呼分裂：`Mr. {player_name}` 译成「X老师」而 `Mr. {mcSurnameBase}` 译成
  「X先生」。统一为 **X先生**（正文里 Clarissa 称呼 `sir` 也一律「先生」，
  `Sensei` 才是「老师」）。
- 「夜总会」与「夜店」指同一间 club：正文 17 处「夜店」、4 处「夜总会」，
  全部统一 `夜总会`。`bar` 是另一家，仍译「酒吧」。
- 「学校」与「学院」指同一处：统一 `学院`（正文以学院为主）。
- `Gallery`=画廊、`Photo Gallery`=照片库，原译「图库照片」已改。
- `END REPLAY` 两处不同译，统一。

### 人名与拼写

克丽丝/克莉丝、达芳妮/达芙妮、诺瓦/诺娃、贝拉/贝尔、特别来宾/特邀嘉宾 全部归一。
开发者的 ID `RogueOne` 在致谢页一直是拉丁，译文里却出现过「侠盗一号」，已还原。
NewGram 上 8 个用户名被机翻成了中文（`.农场小女孩`、`每日梗图`…），按既定约定
全部还原为拉丁——那是世界里别人的账号，译了就不好笑了。

### 语气与语义

- `knocking one of the guards into next year`（英语习语）直译成「撞进了明年」，
  改为「撞得飞了出去」。
- `wingman` 的「僚机」改为「红娘 / 助攻」。
- 逐句精校时抓到的：增译（`#2502` 空出一个「你」）、习语直译
  （`Duty calls`→「任务在召唤」）、时态扭了（过去式译成现在式）、
  断词歧义（「到达斯特的卡车」读成「到达+斯特」）、句不成语（「老天不行」）。
- 对话里 `您`／`妳` 残留清零；行尾 `；` 清零。
- 半角括号统一为全角，包括包裹中文的 `(…)`。
- `第N天` 全局归一为 `第 N 天`（98 处）。

## 没改的，和为什么

- **NewGram 用户名保持拉丁。** 那是世界里别人的账号，译了会破坏它和正文语域的对比。
- **`Principal` 的两种译法并存。** 系统里是「校长」，Director 语境下是「总监」，
  游戏自己就这么用的。
- **`导演` 没有全部改掉。** 有一句 `The interactive director is not enabled here.里的
  `director` 指 Ren'Py 自带的互动导演功能，译成「导演」是对的。
  `The Director`（Sapdavir Amato，校长／总监那个职位）才是「总监」。
  所以 `The Director` 的禁用列表是空的，原因记在
  `docs/glossary.json` 的 `_variant_names.导演`。
- **`en_ref/Days/dayTen.rpy` 没有对应的中文文件。** 游戏自带的 dayTen 本来就没有
  中文翻译条目，不在这个补丁的范围内。
- **`style.rpy` / `wave_shader.rpy` 在英文参考里没有。** 这两个是 mod 自带的文件。
