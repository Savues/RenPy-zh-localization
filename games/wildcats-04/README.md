# WildCats 0.4 — BladeSSR 多功能模组汉化 (Multi-Mod)

> ⚠️ **说明**：本作《WildCats 0.4》游戏本体已原生内置官方简体中文，**本补丁不是游戏本体的汉化**，而是针对第三方 **BladeSSR 多功能模组（作弊菜单 + 选项攻略提示）** 的中文汉化与客户端适配补丁。

《WildCats 0.4》的综合辅助模组（Multi-Mod），基于原作者 **BladeSSR** 的模组二次开发汉化与客户端适配，使其能完美兼容游戏官方中文环境。

| 项目 | 数值 |
|---|---|
| 原引擎版本 | Ren'Py 8.2.0 |
| 补丁方案 | 脚本覆盖（`patch_layout: script-override`） |
| 模组内容 | 作弊菜单（Cheat Menu）+ 选项攻略提示（Walkthrough Hints） |
| 模组词条量 | 150 条选项与提示 |
| 汉化覆盖率 | **100%** |
| 字体方案 | 继承游戏客户端官方中文字体（LXGW WenKai / FZLB / chinafont） |

## 适用对象与作用

原作者 BladeSSR 开发的 Multi-Mod 仅针对原版英文设计，若直接放入开启了官方中文的游戏中，会出现：
1. 选项上的攻略提示（好感/分支）完全失效不显示；
2. 作弊菜单所有内容为英文，且字体锁死西文字体存在方块字（乱码）隐患。

本模组补丁修复了上述问题：
- **攻略提示系统**：完整汉化所有选项加减分、坏结局预警与分支提示，并通过双向映射兼容中文客户端；
- **作弊菜单系统**：全面汉化好感度、角色状态（相识/知己/浪漫）、画廊回忆全解锁、自拍照片全收集、场景旗标，并自动对接客户端内置中文字体。

## 模组功能特性

1. **选项攻略提示（Walkthrough Hints）**
   - 提取自游戏官方中文语言包，选项无论是中文还是英文均能自动匹配。
   - 选项后附加好感度增减、心情变化、恋爱/知己分支路线、坏结局预警、特殊剧情(H)及彩蛋提示。
   - 完美适配长选项文本与紧凑模式，支持直接在作弊菜单中一键开/关。

2. **作弊菜单（Cheat Menu）**
   - 呼出方式：底栏快捷菜单中的“作弊”按钮，或全局快捷键 `Alt + C`。
   - **角色好感与状态**：单独或一键调整角色好感（支持最大值）、关系状态（相识/知己/浪漫），数据与个人资料档案双向同步。
   - **剧情与全局解锁**：调整伊芙心情（Eve Mood）、一键解锁/恢复全 CG 画廊回忆、一键解锁/恢复全角色自拍照片。
   - **场景旗标**：各角色特殊剧情判定旗标开关。

## 安装方法

### 自动化安装（推荐）
```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools\install.ps1 "你的游戏根目录路径"
```

### 手动安装
将 `patch/game/BladeSSRMod` 目录直接复制到游戏的 `game/` 文件夹下即可。
