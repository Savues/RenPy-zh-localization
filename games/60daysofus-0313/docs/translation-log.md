## 做法：三轮

| 轮 | 解决什么 | 判定口径 |
|---|---|---|
| 一 | **对不对** | 漏译、误译、术语、标点、格式 |
| 二 | **像不像这个角色会说话** | 12 个角色的语气基准见下 |
| 三 | **读起来顺不顺** | 只改措辞，不改信息 |

## 一、第一轮：查错与术语

### 术语裁定（每条都有依据，不是口味）

| 英文 | 定译 | 依据 |
|---|---|---|
| `Los Suenos` | 洛斯苏埃诺斯 | 原译 `洛圣都` 是 `Los Santos`（圣）。而游戏原句是 `This is Los Suenos. The city of dreams.` —— `Sueños` 是「梦」，同一句里「梦想之城」和「洛圣都」自相矛盾。全库 39 处**没有一处**英文是 `Los Santos`。改回开发者自带的音译 |
| `Greyhound` | 灵缇 | 原译「灰犬」是照字面翻的代号。行动代号的定译取 `灵缇`（雪貂的一种，敏捷、正面意象），避免与犬科动物混 |
| `Sayid` | 萨伊德 | 原译「赛义德」是另一路音译，与全篇其余译名风格不一致 |
| `Craig` | 克莱格 | 名字框原译 `克雷格`，四句台词却是 `克莱格`。而 `克雷格` 与 `格雷格`（Greg）只差一字。取台词那一版：既与自己的台词一致，又与 Greg 区分得开 |
| `Vatos` | 兄弟帮 | 保留原文的拉丁字母读音不如给个中文称呼好念，且是帮派名，反复出现 |
| `soldier boy` | 大兵仔 | 保留口语的调侃语气，不译成「士兵男孩」 |

### 军衔：这一条最费事，结论也是最有据的一条

游戏**自己的名字框**给了答案：

```
old "SSG.Turner"   → 特纳上士
old "CSM Graves"   → 格雷夫斯一级军士长
old "Cpl.James"    → 詹姆斯下士
```

英文自我介绍也是 `Staff Sergeant Joseph Turner.`。而机翻把 `Sergeant`
一律压成「军士长」，于是**屏幕上的名字框写着上士，人物嘴里念出来的是军士长**。
玩家看得到这个矛盾。

定案：

| 英文 | 定译 |
|---|---|
| `Sergeant` / `Sarge.`（泛称，士兵对上士的称呼） | 中士 |
| `Staff Sergeant` / `SSG` | 上士 |
| `Sergeant Major`（剧本里用于称呼 Graves） | 一级军士长 |
| `Command Sergeant Major` / `CSM` | 一级军士长 |
| `Corporal` / `Cpl.` | 下士 |
| `Sergeant Major Graves`（名字框全称） | 格雷夫斯一级军士长 |

**这里有两轮裁定相反，值得写下来。** 第一轮把全部军衔统一成
`中士` / `上士` / `士官长`（理由同上）。第二轮做语气精修时，有一个分块
以「Adams 在点名的场合不该喊得这么正式」为由，把 `特纳上士` 改回了 `特纳中士`。
发布前复查时按下面三条判掉，恢复了 `上士`：

1. 名字框是玩家**看得见**的，`SSG.Turner` → 特纳上士。台词说中士、
   名字框说上士，是把一个正确的译法改成一个自相矛盾的译法。
2. `Staff Sergeant Joseph Turner.` 是正式自我介绍，用的就是 SSG。
3. 泛称 `Sergeant.` 与具名 `Sergeant Turner` 在英文里本来就是两回事：
   前者是称呼，后者是衔级加姓。中文沿用同一分法。

`docs/glossary.json` 的 `_banned_exempt` 把剩下 3 处合法的「一级军士长」
登记为豁免，其余任何地方再出现「军士长」仍然失败。

### 硬伤类别

| 类别 | 例子（EN → 旧 → 新） |
|---|---|
| 直译腔 | `Just admiring the view, Sergeant.` → `就是欣赏一下风景，长官。` → `看看风景而已，中士。` |
| 同音误听 | `You really trust me enough to give me shells?` → `你真的信任我到愿意给我子弹?` → `…子弹？`（半角问号） |
| 器物错 | `Last flight` 在全程直升机的上下文里被译成「飞机」 |
| 助动词当实义词 | `Yeah, I do.` 被译成「嗯，玩啊。」 |
| 句子不成语 | `老天不行`（「老天」只能独立成感叹词，不能带宾语） |
| 时态扭了 | `couldn't hold`（过去）被译成「守不住」（现在） |
| 指代错 | 句中的 `her` 指弗吉尼亚，却被译成「相信自己」 |
| 主语错配 | `you go figuring out` 被译成第一人称 |
| 语源错位 | A.J. 回应 `Ready?` 的 `Yeah...` 被译成「好了」（应答词误用） |
| 增译 | `H-Hi...` 凭空多出一个「你」；`stock run out` 被译成「已被抢购一空」 |
| 习语直译 | `spray and pray` → 「瞎祈祷」 |

### 平行对白对齐

同一句英文在全库有多处、却译得不一样的情况：**81 组 → 48 组**。

最大的两组是同一段新闻广播在游戏里出现了两次（`script.rpy` 的 2292–2309 与
4512–4529，共 18 行）：第二轮精修了后一处，前一处一直漏着。已按「精修侧为准」
对齐，直接复制文本，以保证 `{i}` 之类的标签逐字一致。`2311–2315 vs 4530–4534`
同理。

剩下的 48 组是合理的变体，不是漂移：短促的应答（`'Yeah.'`、`'Okay.'`、`'Damn.'`、
`'What?'`）本来就会因说话人不同而不同；`'...'` 那组收的是 `好结局` / `坏结局` /
`*尖叫*` 这类旁白标记，压根不是台词；`'Love you too.'` 对多人说时是「我也爱你们」。

## 二、第二轮：语气

第一轮解决「对不对」，第二轮解决「像不像这个人会说话」。
判定口径一句话：**把译文念出来，不像这个角色会说的话就改。**

为 12 个说话角色各写了语气基准（威尔 / 贝丝 / A.J. / 伊薇 / 弗吉尼亚 / 达斯特 /
由美子 / 艾琳 / 瑞亚 / 戴安 / 莫莉 / 军人官方），加上粗口分级和专有名词统一表。

| EN | 旧 | 新 |
|---|---|---|
| `Well, hell...` | 得，好吧…… | 好家伙…… |
| `Damn, man. Have some faith.` | 得了吧老兄，对我有点信心。 | 得了吧，对我有点信心。 |
| `Man, look at you two. Sounds like a couple of old men waiting for the bus.` | 老天，看看你们俩，说话跟等公交车的老头似的。 | 瞧瞧你俩。说话跟等公交的老头似的。 |
| `Can't wait to sleep in a real bed again.` | 真等不及要在真正的床上睡觉了。 | 等不及要在张正经床上睡一觉了。 |
| `The 'Loser Duo'... Haven't heard that in a while.` | '废柴二人组'…… | 「废柴二人组」…… |

### 粗口

**粗口不改成更规范或更软的说法。** 英文有 `fucking` / `shit` 而原译漏掉时可以补足
（「靠……你死定了」→「靠……你他妈死定了」），但「操他妈的」「维京混蛋」这类
原样保留的，一个字不动。中文脏话本身就是可接受的中文表达，
把它「翻译干净」是在替玩家做决定。

## 三、第三轮：润色

只改措辞，不改信息。产出率不高——这是前两轮已经收干净的结果，不是没做事。

| EN | 旧 | 新 |
|---|---|---|
| `I don't think I can keep pretending anymore.` | 我觉得我撑不下去了。 | 我觉得我再也假装不下去了。 |
| `We're seeing gunfights at evacuation points, roadblocks being torn down...` | 撤离点已经出现交火**,**路障也被拆毁…… | 撤离点已经出现交火**，**路障也被拆毁…… |
| `This is Los Suenos. The city of dreams.` | （城市名作「洛圣都」） | 洛斯苏埃诺斯 |

`A.J.` / `AJ` 严格镜像英文原写法（英文本身就混用），只在 `#5403` 那一处
两个写法交叉错了的地方纠正。`.223`、`5.56`、`MAC-10`、`7-亚当-16` 的半角是**正确的**，
是标识符，不动。

## 四、刻意**不**统一的三处

这三处看着像不一致，其实在英文里就是两回事，合并才是错的。

| 英文 | 中文 | 为什么不合并 |
|---|---|---|
| `zombies` | 丧尸 | 威尔开场按大众说法叫「丧尸」（`Zombies. You've seen them in movies before, right?`），知道之后改用更准确的「感染者」（`Visual confirmed... infected.`）。**剧本自己就在教这个区别** |
| `infected` | 感染者 | 同上 |
| `vampires` | 吸血鬼 | `po_p2p2.rpy` 有一句 `Technically, they're zombies, not vampires.` —— 说话人正在纠正别人把感染者叫成吸血鬼。改掉它，这句台词就没了 |
| `squad` / `team` | 班 / 小队 | `script.rpy:1537` 的英文是 `Irene's team`，是「小队」不是「班」 |

## 五、刻意保留的两组同名

| | 次数 | 理由 |
|---|---|---|
| `伊薇`（Evie）/ `伊芙琳`（Evelyn） | 50 / 31 | Evie 是昵称、Evelyn 是全名。英文全篇就是两个人，合并会丢掉昵称感 |
| `达斯汀`（Dustin）/ `达斯特`（Dust） | 2 / 17 | 游戏自己在 `我叫达斯汀，大伙儿都叫我达斯特` 这句里点明了 |
