三个数字不一样，不是打架，是三件不同的事：

- **61,417** 是英文原版的**字面量条数**（`p` 类）。同一句话在脚本里出现十次就算十条。
- **54,402** 是这些字面量**去重后**的英文 key 数，也就是实际需要查词表的不同句子数。
- **53,424** 是成品 `.rpy` 里**去重后**的中文条目数。它比 54,402 少，是因为多条不同英文
  在中文里并成了一句（例如三个不同的英文提示共用一句中文），以及 123 条保留英文的条目
  不产生中文。

`file_loader.rpy`、`gui.rpy`、`loadcorrections.rpy`、`replays.rpy` 的 `p` 类为 0 很正常：
它们分别是加载器、界面字体定义、存档兼容代码和回放索引代码，字符串基本都是资源路径、
颜色值、存档键名。资源路径是 `a` 类，颜色与代码是 `n` 类 —— 这些都**不能**翻，
翻了就是 `Image 'XX' not found` 或存档读不出来。

## 123 条保留英文

分四类，逐条登记在 [`glossary.json`](glossary.json) 的 `_kept_verbatim`（22 条唯一值，
在脚本里出现 123 次）：

1. **Ren'Py 自己的界面** —— `Made with Ren'Py`、`{#auto_page}A`、`Mouse Wheel Up\nClick
   Rollback Side`、`Right Trigger\nA/Bottom Button`。键帽和手柄按键没有中文译法，
   翻了玩家反而找不到键。
2. **存档目录名 `WartribeAcademy`** —— 改了会让玩家读不到自己的旧存档。
3. **星号体舞台指示** —— `*GASP*`、`……{w}*TSK*`、`{i}Imperdiet!{/i}`。全项目统一保留英文，
   这是全大写斜体约定，不是漏翻。
4. **部族语乱码** —— `do gosa hu?`、`Gorasa?`、`vi' husa hu govisa vi do sago ba hu bado.`。
   脚本自己明说角色听不懂这些词、只是鹦鹉学舌地重复，照字面保留乱码才成立。

## 译文落盘

译文不是直接手改 `.rpy`，而是先生成对照表再按位置回写（`strings.jsonl` →
分块 → `translations.json` → 注入）。原因写在 [approach.md](approach.md)：
按行号回写会因为中文比英文短而整体左移，必须有遮蔽骨架兜底校验。

分块 363 个、54,436 行，每块独立翻译以便并行又不互相污染上下文。
